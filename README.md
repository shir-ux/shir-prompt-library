# ספריית הפרומפטים והמדריכים - SDM

ספרייה ציבורית של פרומפטים מוכנים להעתקה ומדריכים לעבודה נכונה עם סוכני AI.
נבנתה עבור **שיר שרביט - שיר שיווק דיגיטלי (SDM)** לשיתוף עם לקוחות.

**הכתובת החיה:** https://shir-ux.github.io/shir-prompt-library/

---

## איך זה בנוי

מקור האמת הוא `data/` - **לא** `index.html`.
`index.html` הוא **תוצר בנייה**. כל עריכה ידנית בו תידרס בבנייה הבאה.

```
data/                 ← מקור האמת
  prompts.json          הפרומפטים
  guides.json           המדריכים
  starter-rules.txt     בלוק 53 הכללים (טקסט גולמי, בתוך מדריך 8)
template/             ← העיצוב והקוד
  page.html             שלד הדף
  styles.css            העיצוב
  app.js                הקוד שמריץ את הדף
assets/
  logo-white.png        הלוגו (מוטמע בדף בבנייה)
  fonts.css             הפונט Rubik מוטמע
build.py              ← בונה את index.html מכל אלה
index.html            ← תוצר. זה מה שעולה לאוויר
```

הדף יוצא **קובץ בודד ועצמאי** - הלוגו והפונט מוטמעים בתוכו.
אפשר לשלוח אותו במייל והוא ייפתח גם בלי אינטרנט.

## להוסיף פרומפט

### הדרך הקלה

לבקש מ-May בצ'אט: *"תוסיפי את הפרומפט הזה לספרייה"* + הפרומפט.
היא מציעה כותרת, תיאור וקטגוריה, מוסיפה, בונה ומעלה.

### ידנית

1. להוסיף רשומה ל-`data/prompts.json`:

```json
{
  "cat": "שיווק ותוכן",
  "name": "🎯 שם הפרומפט",
  "purpose": "מתי משתמשים בו - שורה אחת",
  "text": "הטקסט המלא של הפרומפט"
}
```

2. להריץ:

```bash
python3 build.py
```

3. לדחוף - הכתובת החיה מתעדכנת לבד תוך דקה-שתיים.

**הקטגוריות הקיימות** (כדאי להשתמש בהן ולא להמציא חדשות):
עבודה נכונה עם AI · שיווק ותוכן · ניתוח נתונים · כתיבה ועריכה ·
תכנון וקבלת החלטות · מחקר ואיסוף מידע · יצירתיות וסיעור מוחות ·
פרודוקטיביות · בקרת איכות

`build.py` עוצר עם שגיאה אם חסר שדה, אם יש שם כפול, או אם מספור המדריכים לא רציף.

## להוסיף מדריך

רשומה ב-`data/guides.json` עם `n` (המספר הבא ברצף), `title`, `excerpt`, ו-`html`.
ה-`html` הוא גוף המדריך. מחלקות העיצוב הזמינות:

| מחלקה | שימוש |
|---|---|
| `cal cal-info` | קופסת מידע (סגול) |
| `cal cal-warn` | אזהרה (זהב) |
| `cal cal-alert` | חשוב (אדום) |
| `cal cal-note` | הערה / פרומפט להעתקה (ירוק) |
| `tbl-wrap` | לעטוף כל `<table>` - כך היא גוללת במובייל ולא שוברת את הדף |
| `pre class="block"` | בלוק קוד כהה |
| `a data-goto="7"` | קישור למדריך אחר בתוך אותו דף |

## הערה על פרטיות

הריפו ציבורי, ולכן **כל מה שנכנס לכאן גלוי לכולם**.
לא להכניס שמות לקוחות, מספרים עסקיים, תמלולי שיחות, או כל מידע פרטי -
רק פרומפטים ומדריכים גנריים.
